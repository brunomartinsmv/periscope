Do arquivo bruto ao relatório publicável

1

Importar e organizar

Carregue planilhas e exportações do Espacenet, Patentscope e DPMA ou cadastre patentes manualmente, mantendo prioridades, classificações e anexos PDF no mesmo projeto.

2

Harmonizar depositantes e inventores

Localize grafias divergentes com o índice fuzzy em Apache Lucene 9, agrupe variações sob um nome canônico com país, UF e natureza jurídica e aplique regras em lote.

3

Explorar indicadores e exportar

Filtre por janela temporal, natureza do depositante e nível IPC ou CPC, inspecione os 13 gráficos e tabelas interativas e baixe os dados consolidados em CSV.

Feito para pesquisadores, NITs e equipes de P&D

Cada tela cobre uma tarefa real do estudo patentário, da triagem inicial de documentos até a revisão colaborativa com observadores.

13 relatórios e exportação CSV

Ranking de depositantes e inventores, séries temporais por depósito, publicação e prioridade, classificações IPC e CPC com descrição das seções, natureza jurídica, distribuição por estado e região no Brasil e tabela de prioridade nacional.

Harmonização reversível com Lucene 9

Sugestões por similaridade de tokens destacam variações de uma mesma organização ou inventor. Regras podem ser editadas ou desfeitas sem perder o histórico dos documentos originais.

Dossiê completo e anexos em GridFS

Edite títulos, resumos, códigos IPC/CPC, datas e múltiplas prioridades diretamente no navegador, com upload e download de documentos PDF vinculados a cada projeto.

Permissões por projeto e sessão segura

Separe proprietários, observadores e administradores com autenticação por cookie HttpOnly, revogação imediata ao encerrar sessão ou trocar senha e validação estrita de acesso em cada recurso.

Interface bilíngue em um único pacote

Alterne entre português e inglês sem recarregar a página. A aplicação React é empacotada junto à API REST e ao núcleo analítico em um único WAR pronto para servidor ou container.

Arquitetura e implantação

Projetado para rodar tanto em estações locais quanto em servidores institucionais com HTTPS automático e monitoramento de saúde.

Interface React 19, TypeScript, Recharts e suporte a português e inglês em /periscope/app/
API REST Jakarta EE 10 (JAX-RS) em WildFly 34, documentação OpenAPI 3 em /openapi e health check em /rest/health
Harmonização Apache Lucene 9 com índice Fast-Join para busca fuzzy de depositantes e inventores
Persistência MongoDB 7 via Morphia 2.5 e driver 5.2, armazenamento de PDFs em GridFS 
# Sobe MongoDB 7 e WildFly 34 com a interface embutida
git clone https://github.com/brunomartinsmv/periscope.git
cd periscope
docker compose up --build -d

# Aplicação: http://localhost:8080/periscope/app/
# OpenAPI:   http://localhost:8080/openapi
# Saúde:     http://localhost:8080/periscope/rest/health
# Configure domínio, MongoDB, segredo JWT e senha admin
cp .env.example .env
$EDITOR .env

# Sobe MongoDB autenticado, Periscope e Caddy com HTTPS
docker compose -f docker-compose.prod.yml up --build -d
# 1. Compila a interface e incorpora ao WAR
cd periscope-ui && npm ci && npm run build:war && cd ..

# 2. Executa os testes e gera o periscope.war (JDK 21)
mvn -B clean verify

# 3. Publica no diretório deployments do WildFly 34
cp periscope-web/target/periscope.war \
  /opt/jboss/wildfly-34.0.1.Final/standalone/deployments/
Em ambiente local, a conta inicial padrão é admin com senha 123456.
